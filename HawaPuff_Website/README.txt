HAWAPUFF WEBSITE — CARA PAKAI
1. Ekstrak HawaPuff_Website.zip.
2. Buka index.html di browser, atau buka folder melalui Visual Studio Code dan gunakan Live Server.
3. Buka script.js untuk mengganti nomor WhatsApp toko:
   const NOMOR_WHATSAPP_TOKO = "628xxxxxxxxxx";
   Gunakan format 62..., tanpa + atau spasi.
4. Di script.js, kamu bisa mengubah nama dan harga produk pada bagian const produk.
5. Jangan pisahkan index.html, script.js, dan folder assets.

CATATAN:
- Harga produk ukuran L/M/S/XL masih berupa nilai awal dan perlu kamu koreksi sesuai harga sebenarnya.
- Harga lain disusun berdasarkan informasi dari percakapan; cek kembali sebelum website dipublikasikan.
- Website ini merupakan katalog front-end, belum memakai database, login, pembayaran otomatis, atau sistem pengiriman.
- Untuk meng-online-kan website, unggah folder ke hosting statis seperti GitHub Pages atau Netlify.
